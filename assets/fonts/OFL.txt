THE ASHGROVE TIMES - VENDORED FONT LICENSES
===========================================================================

Every TTF in this directory is licensed under the SIL Open Font License 1.1.
They are committed so the hero-card renderer works fully offline, with no
network fetch and no system font dependency, inside a restricted sandbox.

PROVENANCE AND BAKE RECIPE (reproducible; fontTools is BUILD-TIME ONLY and is
never a runtime dependency of this project):

  source repo   https://github.com/google/fonts  (ofl/<family>/)

  PlayfairDisplay-Bold.ttf     from PlayfairDisplay[wght].ttf     pin wght=700
  PlayfairDisplay-Black.ttf    from PlayfairDisplay[wght].ttf     pin wght=900
  SourceSerif4-Regular.ttf     from SourceSerif4[opsz,wght].ttf   pin wght=400 opsz=12
  SourceSerif4-Semibold.ttf    from SourceSerif4[opsz,wght].ttf   pin wght=600 opsz=12
  SourceSerif4-Italic.ttf      from SourceSerif4-Italic[opsz,wght].ttf
                                                                  pin wght=400 opsz=12
  OldStandard-Regular.ttf      shipped static upstream; copied verbatim

  pinned with fontTools.varLib.instancer.instantiateVariableFont(
      font, pins, updateFontNames=True)

  opsz is pinned to a text grade (12) rather than the 20pt default because
  Discord scales the 1200x630 hero to roughly 550px wide, so every glyph is
  read small.

Upstream note: the google/fonts path for Old Standard TT is oldstandardtt/ but
the file itself is named OldStandard-Regular.ttf, NOT OldStandardTT-*.

The three upstream OFL.txt files follow verbatim.
